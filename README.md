# Chroma Layer Studio
Mobile-first, no-AI manual 2D character layer cutter.

## ChromaToons workflow
1. Download the official ChromaToons human texture/chart from the official page.
2. Upload Front character PNG.
3. Cut layers manually with polygon selection.
4. Open Export -> load the official chart PNG.
5. Open Atlas Editor and place/resize/rotate the layers on the exact chart.
6. Export `ChromaToons_Texture_2048.png`.
7. In ChromaToons SP character, use `+` -> `Tex` and select the 2048x2048 PNG.

The app deliberately does not invent chart coordinates. ChromaToons' official page states that the body parts must be arranged in the supplied chart positions and the image must be PNG 2048x2048.
